# Support

## Getting help

1. Check **Troubleshooting** and **Known limitations** in the [README](README.md).
2. Open **Output → Probato PR** to read the log of the last operation.

## Reporting a bug

Please include:

- Probato PR version (Extensions view) and VS Code version (`Help → About`).
- Operating system, and whether you use WSL, Dev Containers or Remote SSH.
- The review scope you ran and what you expected.
- The relevant lines of **Output → Probato PR**.
- If useful, an exported **JSON report**. Reports contain file paths, rule IDs and redacted output excerpts; review them before sharing and remove anything you consider confidential.

Do not include source code you are not allowed to share. Security issues: follow [SECURITY.md](SECURITY.md) instead.

## Feature requests

Describe the problem you want solved, a small example, and the languages or tools involved.

## Channels

Issues: https://github.com/Drako01/probato-pr/issues (once the repository is public). Meanwhile, contact **addistefano76@gmail.com** (subject: `Probato PR support`).

## Support policy

During the 0.x series, fixes are released for the latest version only. There is no guaranteed response time; security reports are acknowledged within 5 business days.
